# My portfolio

After some time thinking about making a **portfolio**, I was finally able to achieve it, but not before going through more than 10 video tutorials, 20 articles, etc. It took a while because I didn't know how to do many things, I had to learn a lot.

My idea was to have a space to show my projects and my contact information, I realized that my personal projects should not be easy, they should take a challenge and that I could advance, so I added sections and the idea of ​​a **blog** arrived.

---

## Blog

The idea of this blog is not to talk so much about myself, it is more focused on **software development** perhaps making tutorials or explaining how the construction of some of my projects was, improving my writing and maybe at some point writing anecdotes, adventures and those little things.

The most complicated thing was deciding to do it, technically it was also complicated since it was not the idea at the beginning so there is no backend or database, nor tools or templates like **docusaurus** to facilitate development, everything is locally. But it has a disadvantage and that is, what will happen when you have many files? The project will be very heavy 🤔.

&nbsp;&nbsp;

### **Implementation**

Deciding which method or format to use to prepare the publications, the first option was **markdown** .md, which allows structuring content without the need to include _HTML_ or _CSS_.
This makes content creation much easier but complicates implementation: Search the .md file dynamically by publication, obtain the text within that file and then render it stylized along with its metadata (title, author, date...).

With a not very complicated structure, I believe that to add more publications it is only necessary to add a new file in markdown .md format and some extra data such as title, date, tags...

Something complicated that I still can't manage is to display locally hosted images, for now I upload them to **Imgur**. Posts only load when they are opened, so if the number of posts increases the initial loading will not take longer.
