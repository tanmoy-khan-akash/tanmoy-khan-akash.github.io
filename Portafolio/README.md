# **TANMOY KHAN AKASH PORTFOLIO**

This project is my professional portfolio where I showcase my skills, experience, and areas of specialization.

This portfolio is a PWA, so you can install the application on your device.

## **TECHNOLOGIES**

I used the following technologies for this portfolio:

- ReactJS
- CSS Modules
- Netlify
- PWA

## **USAGE**

To use this project:

- Clone the repository: `git clone https://github.com/Tono2007/portafolio.git`
- Install dependencies: `npm install` or `yarn install`
- Run it: `npm start` or `yarn start`
